# Cinema Guru

Application de films en React, pour le projet Holberton. On se connecte, puis on cherche des films, on les met en favoris ou dans « watch later ».

## Installation

Le sujet demande yarn, pas npm.

```bash
yarn
yarn dev
```

Le serveur de dev est sur le port 3000 : http://localhost:3000

L'onglet du navigateur doit afficher `Holberton - Cinema guru`.

L'API tourne à part, avec Docker, sur http://localhost:8000. Sans elle, la connexion et les listes de films ne répondent pas.
